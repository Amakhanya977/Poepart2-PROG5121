# Poepart2-PROG5121
QuickChat is a java-based application developed as part of my IT coursework.
The application allows users to register, login, send messages and view message details.
features:
Message creation
Message hash generation
Recipient cellphone number validation
Displaying message details
Technologies used are:
Java
GitHub
Structure:
Poepart2.java - Main application 
Login.java - Login functionality
Message.java - Message creation, validation, hashing and sending
MessageText.java - Message testing

This application demonstrates the application of java programming concepts.
